Save bank SMS automatically on iPhone

iPhones don’t let any app read your messages, but the Shortcuts app can save each bank SMS to a file as it arrives. Set it up once:

  1. In Shortcuts, tap + and name the new shortcut Save Bank SMS.
  2. Add a Text action. Put Shortcut Input in it, and on the next line put Current Date inside square brackets, like [Current Date].
  3. Add Append to Text File. Set the file path to bank-sms.txt and turn on Make New Line.
  4. Open the Automation tab, tap +, choose Message, and set Message Contains to debited. Pick Run Immediately, tap Next, then choose Save Bank SMS.
  5. Repeat step 4 for credited and spent, plus Sent Rs if your bank’s UPI messages start with “Sent”.

Each bank SMS now lands in iCloud Drive › Shortcuts › bank-sms.txt. Whenever you want to catch up, tap Load saved SMS and pick that file. Messages already in your ledger are hidden, so loading the same file again is safe.

Good to know

  • GPay, PhonePe, Paytm UPI and BHIM pay straight from your bank account. Add the bank account, not the app: its SMS covers every UPI payment.
  • Moving money between your own accounts and paying a card bill are left out of monthly totals, so nothing is counted twice. Mark those entries as Self transfer or Card bill payment.
  • Add your debit card’s last 4 digits to its bank account, so card spends land in the right place.
  • Your entries are private to you. Anyone you share this page with sees an empty ledger.
